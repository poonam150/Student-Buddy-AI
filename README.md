# 🤖 Student Buddy AI: Mental Health Companion

A professional Streamlit web application designed to support student well-being using **Natural Language Processing (NLP)** and **Large Language Models (LLMs)**.

## 🌟 Features
- **AI Counseling:** Powered by `TinyLlama-1.1B` to provide actionable self-care tips.
- **Sentiment Analysis:** Uses `TextBlob` to detect emotional polarity in real-time.
- **Mood Tracking:** Visualizes emotional trends with interactive line charts.
- **Safety First:** Includes automated emergency resource triggers for high-distress scores.
- **Zen Zone:** Features a CSS-animated breathing guide and a digital journal.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **AI Model:** Meta-Llama (via Hugging Face)
- **Data:** Pandas & TextBlob

## 🚀 How to Run
1. Clone this repository.
2. Install requirements: `pip install -r requirements.txt`
3. Add your Hugging Face Token to a `.env` file.
4. Run the app: `streamlit run app.py`
